# Tese Studio — Studio Hire in Harare

A modern, responsive landing page for **Tese Studio** — a private photo & video studio in Groombridge, Harare, Zimbabwe.

## Features

- **Hero Section** — Split layout with background image, headline, and overlapping quick-contact pill bar
- **Studio Setups Gallery** — Interactive accordion-style gallery with 4 curated studio spaces
- **Booking Form** — Sticky booking panel with validation, synced with gallery selection
- **Explore Section** — Grid of studio photos with fullscreen lightbox viewer
- **Responsive Design** — Mobile-first, works on all screen sizes
- **Animations** — GSAP-powered scroll animations, accordion transitions, and micro-interactions
- **Accessibility** — Semantic HTML, ARIA labels, keyboard navigation, focus management

## Studio Setups

1. **White Cyclorama** — Clean infinite white backdrop, ideal for portraits & product
2. **Moody Portrait Corner** — Low-key lighting with textured backdrops for dramatic portraits
3. **Creative Loft** — Sunlit open loft with props and furniture for lifestyle shoots
4. **Black Box** — Fully blacked-out space for video and controlled lighting

## Tech Stack

- Vanilla HTML/CSS/JS (single file)
- **GSAP** + ScrollTrigger + SplitText for animations
- **React** (via esm.sh) for AccordionGallery and StarBorder components
- **Font Awesome** for icons
- **Poppins** font from Google Fonts
- Images from Unsplash (with picsum fallback)

## Quick Start

Simply open `index.html` in a browser — no build step required.

## Deployment

Host on any static hosting (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).
