# Pure Pixel Perfect (98)

Create a pixel-perfect recreation of the provided UI design using pure HTML5 and CSS3. Do not use React, Next.js, Vue, Bootstrap, Tailwind CSS, or any other framework or library. The output should be clean, semantic, production-quality code that closely matches the reference design.

General Requirements

Recreate the layout, spacing, typography, alignment, colors, and overall visual appearance as accurately as possible.

Use semantic HTML elements such as <header>, <nav>, <main>, <section>, <article>, and <footer>.

Organize the code with readable structure and meaningful class names.

Write well-commented code where necessary.

Ensure the layout is fully responsive across desktop, tablet, and mobile devices.

Images

Do not use the original images from the reference.

Wherever the design contains a hero background image, replace it with a clearly marked placeholder using a background image URL or a styled placeholder block labeled "Hero Background Placeholder".

Wherever the design contains photos (such as the couple image or any other illustrations), replace them with placeholder images labeled appropriately (for example, "Image Placeholder" or "Couple Image Placeholder").

Maintain the same dimensions, positioning, border radius, and aspect ratio as shown in the reference.

Hero Section

Recreate the hero section exactly as displayed in the design.

Use a placeholder background image while preserving overlays, gradients, text positioning, buttons, and content alignment.

Match the height and proportions of the original layout.

Content Sections

Reproduce every visible section in the design in the correct order.

Preserve the layout hierarchy, including columns, cards, grids, icons, statistics, testimonials, feature blocks, and call-to-action areas if present.

Use placeholder text only where the original text is unreadable; otherwise, keep the visible wording.

Styling

Use modern CSS with Flexbox and CSS Grid where appropriate.

Match padding, margins, shadows, borders, hover effects, rounded corners, and transitions from the reference.

Ensure buttons, links, and interactive elements have hover and focus states.

Accessibility

Include descriptive alt attributes for all placeholder images.

Use a logical heading structure (h1, h2, h3, etc.).

Ensure sufficient color contrast and keyboard-friendly interactions where applicable.

Deliverables

Provide complete HTML and CSS files that can be opened directly in a browser.

Do not leave incomplete sections or TODO comments.

Make the result visually as close to the provided design as possible while substituting all images with placeholders.

The final output should be polished, responsive, and ready for further customization.
