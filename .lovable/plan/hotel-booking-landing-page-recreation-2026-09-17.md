# Hotel booking landing page recreation

## Build
- Create a standalone `index.html` using semantic HTML for the header, hero, booking search, offers, and popular hotels sections visible in the reference.
- Create a separate `styles.css` with a close desktop match and responsive tablet/mobile layouts.
- Replace every photograph with labeled, accessible placeholder artwork while preserving proportions, cropping, overlays, and rounded corners.
- Add polished hover, focus, and reduced-motion states without adding frameworks or libraries.

## Visual direction
- Match the reference's airy white and pale-aqua canvas, black geometric typography, turquoise actions, soft shadows, and compact rounded controls.
- Preserve the reference's overlapping booking bar, spacious section rhythm, paired offer cards, three-column hotel gallery, and small carousel indicators.

## Delivery and verification
- Save both browser-ready files in a single deliverable folder.
- Verify the page directly in Chromium at desktop and mobile widths, checking alignment, overflow, labels, and all visible content.
